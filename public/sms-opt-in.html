Winnbell — SMS Opt-In & Phone Verification Consent

Last updated: June 22, 2026

What this program is

Winnbell sends one-time passcodes (OTP) by SMS for the sole purpose of phone number verification. This is used only to confirm a user is a real person and to prevent duplicate accounts (one phone number per account).

  • A text is sent only when the user actively requests it by entering their own phone number and tapping Send Code.
  • One message per request. There is no recurring, promotional, or marketing messaging of any kind.
  • A phone number is never required to use the service. Account sign-up and login use email only and never send SMS.

Where and how users opt in

The opt-in happens on the in-app Phone Verification screen, which is the only place in the product where a phone number is collected. The full flow is:

  1. The user opens the Phone Verification screen inside the Winnbell app.
  2. The user types their own phone number into the labeled "Phone number" field.
  3. The consent statement is displayed directly with that field, immediately above the Send Code button (shown in full below).
  4. The user taps Send Code. Only then is a single one-time verification code sent by SMS.

Opt-out and help

Users can opt out at any time by replying STOP to any message, and can reply HELP for help. Mobile phone numbers are never shared with third parties or affiliates for marketing or promotional purposes. SMS delivery is facilitated by Twilio, Inc. solely for the purpose of delivering verification codes.
